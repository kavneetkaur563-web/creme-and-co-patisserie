# Crème & Co. Pâtisserie 🧁

**Live Website:** [https://github.io](https://github.io)

## Overview
**Crème & Co. Pâtisserie** is a multi-page luxury e-commerce storefront crafted during the **ALTA Builder 30-Day Project Challenge**. It features an artisan dessert catalog, curated collections, brand storytelling, a dynamic shopping cart with live subtotal/shipping calculations, and a complete checkout flow.

## Pages Included
* **Home (`index.html`):** Hero showcase, quality guarantees, *Handcrafted Delights* product grid, and *Our Story* preview.
* **Shop (`shop.html`):** Interactive product catalog with category tabs, sidebar filters, and one-click *Add to Cart* buttons.
* **Collections (`collections.html`):** Occasion-based dessert curations (*Birthday, Anniversary, Celebration*).
* **Our Story (`story.html`) & Journal (`journal.html`):** Editorial brand story, core values, and baking guides.
* **Shopping Cart (`cart.html`) & Checkout (`checkout.html`):** Live quantity controls (`+` / `−`), automatic free-shipping threshold ($30+), and order confirmation.
* **Account (`login.html` / `signup.html`) & Contact (`contact.html`):** Customer authentication forms and patisserie inquiry page.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Design System, CSS Grid & Flexbox), Vanilla JavaScript (`localStorage` Cart Engine)
* **Deployment:** GitHub Pages
